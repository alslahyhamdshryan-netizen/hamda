# عبد الإله HR — نظام إدارة الموارد البشرية

## تشغيل سريع

### Windows

1. ثبّت Python 3.11 أو أحدث، وNode.js 20 أو أحدث، وpnpm.
2. افتح مجلد المشروع.
3. شغّل `run_project.bat`.
4. افتح `http://localhost:3000`.
5. سجّل الدخول:
   - المستخدم: `admin`
   - كلمة المرور: `Admin@12345`

### Linux / macOS

```bash
chmod +x run_project.sh
./run_project.sh
```

ثم افتح `http://localhost:3000`.

## لوحة إدارة Django

```text
http://127.0.0.1:8000/admin/
```

الحساب التجريبي يتم إنشاؤه تلقائيًا عند تشغيل السكربت.

## مكونات المشروع

الموظفون، الأقسام، الحضور والانصراف، طلبات الإجازات، الرواتب، المهام، المستخدمون والصلاحيات، ولوحة مؤشرات إدارية مرتبطة بقاعدة SQLite عبر Django ORM.

## ملاحظات التسليم

هذه نسخة تعليمية جاهزة للعرض الأكاديمي. بيانات العرض تُحفظ في `db.sqlite3` بعد أول تشغيل. لا تضع بيانات موظفين حقيقية قبل تغيير `SECRET_KEY` وكلمة مرور المدير وتعطيل `DEBUG` في بيئة الإنتاج.

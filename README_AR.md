# عبد الإله HR — نظام إدارة الموارد البشرية

## التشغيل السريع على Windows

1. ثبّت Python 3.11 أو أحدث، وNode.js 20 أو أحدث، وpnpm.
2. فك الضغط وافتح مجلد `عبد الإله HR`.
3. اضغط مرتين على `run_project.bat`.
4. ستفتح واجهة المشروع تلقائيًا على:

```text
http://127.0.0.1:8000/
```

الآن Django هو الخادم الوحيد: يعرض واجهة React المصممة، ويخدم ملفاتها، ويربط تسجيل الدخول والبيانات وقاعدة البيانات من نفس العنوان.

## بيانات الدخول

```text
اسم المستخدم: admin
كلمة المرور: Admin@12345
```

## لوحة إدارة Django

```text
http://127.0.0.1:8000/admin/
```

## التشغيل اليدوي

```powershell
python manage.py migrate
python setup_demo.py
pnpm install
pnpm build
python manage.py runserver 127.0.0.1:8000
```

ثم افتح `http://127.0.0.1:8000/`.

## مكونات النظام

إدارة الموظفين، الأقسام، الحضور والانصراف، الإجازات، الرواتب، المهام، المستخدمين والصلاحيات، ولوحة مؤشرات HR مرتبطة بـDjango ORM وقاعدة SQLite.


## الدخول الافتراضي

عند تشغيل المشروع محليًا تفتح الواجهة مباشرة في وضع العرض الافتراضي. وللدخول بحساب Django الإداري استخدم:

```text
اسم المستخدم: admin
كلمة المرور: Admin@12345
```

يتم تجهيز الحساب والبيانات تلقائيًا عبر `setup_demo.py`.
